- Обычный набор явно отделён от NativeBackupPhaseInstrumentedTest: этот тест требует специального многофазного OS backup/restore. Он исключён фиксированным профилем, обозначен в интерфейсе и журнале, не считается пройденным.

## Открытое падение — не скрыто фильтром

ExampleInstrumentedTest.useAppContext требует packageName ровно com.animacode.quizapp либо com.animacode.quizapp.debug. Реальный изолированный пакет com.animacode.quizapp.animadevtests.j04101237000000000000000000000021.debug этому условию не соответствует.
Итог честно FAILED / TESTS_FAILED. Полностью зелёный инструментальный набор QuizApp НЕ заявляется.

Подготовлен патч docs/proposed-quizapp-context-test.patch: вместо двух литералов сравнить реальный context.packageName с BuildConfig.APPLICATION_ID того же Gradle-варианта. Это сохраняет проверку идентичности и поддерживает изолированный APK. git apply --check прошёл на точной копии исходного файла из SHA1ecd10c. Патч не применён и на Android не испытан.
Для изменения теста в отдельной GitHub test-ветке QuizApp требуется разрешение владельца: сохраняется его прежний запрет «Не изменять исходники QuizApp». main и текущую рабочую копию менять не требуется; после разрешения можно проверять отдельный worktree.

## Приёмка через приложение

1. Установить dev.27 поверх dev.26 без удаления приложения.
2. Если показано обновление помощника, нажать его кнопку после завершения прежнего задания. SQLite, история и старые Job ID сохраняются.
3. Открыть AnimaQuiz → Тесты: карточки должны соответствовать текущей теме. Проверить журнал в светлой и тёмной теме.
4. Во время отдельного разрешённого задания следить за «Остановить»: автоматический опрос не должен менять доступность/цвет. Подтверждение отмены во время настоящего RUN_COMMAND QUERY, выход, поворот и force-stop остаются проверкой владельца.
5. До применения предложенного патча инструментальный набор QuizApp может честно закончиться 151/152 из-за ExampleInstrumentedTest. Не считать это успешным полным прогоном.
6. Старые результаты, SAF-папка, история и журналы должны оставаться доступными.
