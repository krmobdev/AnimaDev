- Обычный набор явно отделён от NativeBackupPhaseInstrumentedTest: этот тест требует специального многофазного OS backup/restore. Он исключён фиксированным профилем, обозначен в интерфейсе и журнале, не считается пройденным.

## Приёмка через приложение

1. Установить dev.27 поверх dev.26 без удаления приложения.
2. Если показано обновление помощника, нажать его кнопку после завершения прежнего задания. SQLite, история и старые Job ID сохраняются.
3. Открыть AnimaQuiz → Тесты: карточки должны соответствовать текущей теме. Проверить журнал в светлой и тёмной теме.
4. Во время отдельного разрешённого задания следить за «Остановить»: автоматический опрос не должен менять доступность/цвет. Подтверждение отмены во время настоящего RUN_COMMAND QUERY, выход, поворот и force-stop остаются проверкой владельца.
5. Исправление ExampleInstrumentedTest находится только в отдельной test-ветке. Запуск прежнего main может по-прежнему закончиться 151/152; приложение не скрывает эту ошибку.
6. Старые результаты, SAF-папка, история и журналы должны оставаться доступными.

Новые функции и глобальный редизайн не выполнялись. QuizApp изменён только в одном тесте отдельной test-ветки; main и исходная рабочая копия сохранены. После передачи APK работа остановлена до приёмки.
