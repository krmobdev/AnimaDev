## P0 — безопасный выбор ADB-устройства для инструментальных тестов

**Обнаруженный дефект 22.10.2026:** `adb devices -l` в Termux показал только `198.18.0.1:38757 device product:RMX3301 model:RMX3301` (Realme), а экран AnimaDev сообщил «ADB подтвердил Pixel». **Pixel 7 не находился среди подключённых ADB-устройств в момент проверки.**

Причины в исходниках:

- `AdbDeviceGateway.refresh()` принимает **любое одно** авторизованное ADB-устройство и показывает «устройство готово», не сверяя модель, serial и явный выбор пользователя.
- При указанном endpoint и ровно одном уже подключённом устройстве ветка `ALREADY_CONNECTED` пропускает соединение с запрошенным Pixel, даже если подключён другой телефон.
- `AdbDeviceGateway.recentDevice()` ориентируется на число устройств и срок проверки, но не на подтверждённую личность цели.
- `runner/gradle_tests.py:execute_device()` делает `ANDROID_SERIAL=devices[0]` при единственном устройстве; `adb_endpoint` пытается использовать только когда список пуст. **Инструментальные тесты могут попасть на невыбранный телефон.**
- `validLanEndpoint()` принимает RFC1918 IPv4; на предоставленном скриншоте Pixel 7 адрес Wi-Fi-отладки отображается также как `Android_205HXULP.local:40959`. Текущий Termux `adb mdns services` ответил «mdns is not supported by this version of adb»; поддержка `.local` требует отдельной проверки, а не обещания совместимости.

- [ ] Реализовать явный выбор **целевого устройства** в UI: список `adb devices -l` с серийным номером/endpoint, реальной моделью (`adb -s <serial> shell getprop ro.product.model`), статусом и кнопкой «Использовать для тестов». Никаких захардкоженных строк «Pixel» для неидентифицированного устройства.
- [ ] Отдельно показывать **текущий/внутренний ADB** и **выбранный тестовый Pixel**. Не считать `198.18.0.1:38757 / RMX3301` Pixel из-за того, что он единственный.
- [ ] Если выбранный endpoint не совпадает с установленным соединением, не использовать `ALREADY_CONNECTED`. Предлагать явно подключить целевое устройство, **не отключая существующее подключение** и не перезапуская общий `adb server`.
- [ ] Поддержать понятное ручное подключение IPv4:порт, а `.local:порт` — только после подтверждения реальной работы резолвера в Android/Termux или через безопасный показ альтернативного числового адреса. Не сканировать сеть, не угадывать порт и не подменять порт сопряжения портом соединения.
- [ ] При запуске `TEST_DEVICE` обязательно заново проверить **тот же** явно выбранный serial, статус `device`, модель/идентификацию и Git SHA; запускать Gradle только с `ANDROID_SERIAL=<confirmed selected serial>`. При пропаже, смене либо неоднозначности — **fail closed**, без перехода на `devices[0]`.
- [ ] Если доступны два телефона, один offline или emulator, показывать раздельные статусы и позволять безопасно выбрать единственный подтверждённый target. Нельзя запускать тесты на собственном телефоне владельца по ошибке.
- [ ] Сохранить неразрушающее поведение: никаких `adb kill-server`, `adb disconnect`, сброса сопряжений и фоновых установок без явного действия.

**Приёмка:** при наличии Realme и отсутствии Pixel кнопка инструментальных тестов не объявляет Realme «Pixel» и не запускает тесты; после явного выбора/подтверждения Pixel `ANDROID_SERIAL` совпадает именно с ним. После потери Pixel тесты блокируются, без автоматического переключения на Realme.
