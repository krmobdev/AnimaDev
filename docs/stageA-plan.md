Риски и проверки:
- Копирование и поиск сохраняют исходный текст; цвет учитывает структуру события,
  а не слово error в произвольном аргументе. Чанки не разрезают строку/метку времени.
- Доступ SAF может исчезнуть. Проверка при возврате Activity, повторный выбор
  или единоразовый отказ с возвратом Downloads. Не создавать Builds&Report.
- Создавать уникальное имя файла; не перезаписывать существующие файлы.
  Удалять при сбое только новый частичный файл, созданный текущим экспортом.
- Нельзя группировать по названию/remote: использовать проверенную общую .git.
  Старые записи без идентичности не объединять до подтверждения метаданных.
- Главное имя ветки определяется только по валидному origin/HEAD. Без этих
  сведений состояние неизвестно; main/master не угадывать. Fetch не выполняется.
- Просмотр веток ограничен 40 записями и существующей политикой безопасного
  чтения Git; новая команда BRANCHES не относится к runner исполнения.
