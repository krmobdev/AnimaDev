# AnimaDev dev30 — экраны сборки, тестов и открытие APK

Дата: 2026-10-10. Ветка: feature/termux-probe.
Проверенный исходный коммит: eb787babcc4bff103f8658d072137157e93c96d5.
Версия: 0.4.0-beta.8-dev.30, versionCode 44.

## Изменения

- Компактная шапка содержит проект, ветку и SHA. Результаты и мониторы принадлежат своим разделам.
- Сборка разделена на Debug APK и Release AAB; тесты — на Unit-тесты и На устройстве.
- Монитор выполняющихся тестов и последний результат находятся внутри выбранного раздела. Чужие операции и проекты отфильтрованы.
- Настройки ADB сворачиваются. Подключение, проверки Git, блокировка очереди и восстановление неизвестных заданий сохранены.
- Последний результат Debug-сборки сохраняется на экране после Git-проверки.
- Для APK кнопка «Открыть» на экране и в уведомлении открывает установщик через termux-open. Перед открытием проверяются путь, размер и SHA-256; установщику передаётся проверенная приватная копия через механизм URI Termux.
- AAB открывается как файл для публикации; для установки предлагается собрать Debug APK.
- Исправлена ошибка Lint NonObservableLocale в форматировании даты Git.

## Проверки

- JVM: 189/189, ошибок и пропусков нет.
- Pixel 7, Android 17, ADB: полный инструментальный набор 23/23, ошибок и пропусков нет. Пять новых проверок охватывают разделение результатов и мониторов, вкладки сборки, нажатие кнопки APK и сохранность последней ошибки сборки.
- Python: 216/216. Семь новых проверок охватывают MIME установщика, проверенную копию, AAB, изменение содержимого, размер, символические ссылки, путь и ошибку открытия.
- :app:lintDebug: успешно; существующие предупреждения не скрывались baseline или suppress.
- :app:assembleDebug и :app:compileDebugAndroidTestKotlin: успешно.
- ZIP CRC, версия/applicationId, встроенные файлы runner и обработчика открытия и подпись APK проверены.

Нажатие APK проверено с подменой службы в изолированном тестовом приложении; Python проверяет вызов открывающей команды без установки. Подтверждение установки и разрешение установки из Termux остаются системным действием пользователя Android. При первом открытии Android может запросить это разрешение.
