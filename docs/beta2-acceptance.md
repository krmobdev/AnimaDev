## Изменения

- Нижняя навигация только на корневых экранах Проекты/Termux. Стандартная
  стрелка на внутренних экранах; меню настроек вместо постоянного «Вид».
  Возврат из Termux открывает список, не прежний инструмент. Выбранный проект
  сохраняется отдельно; повторное открытие настроек не ломает возврат.
  Восстановление Activity не воспроизводит прежний переход из уведомления.
- Компактный список проектов, отдельная кнопка добавления, контекстное удаление
  с подтверждением. Удаляется только запись. Длинные имена отображаются одной
  строкой с явным многоточием; путь доступен в метаданных выбранного проекта.
- Панель проекта: branch/SHA/dirty и четыре компактные строки инструментов.
  Сборка и неподдержанные инструменты недоступны прямо в панели.
- Единая Material 3 типографика, динамические цвета, темы, стандартные Google
  Material Symbols Outlined. Форма иконок взята из официального набора;
  AppCompat tint убран, цвет задаёт Compose-тема. Меню/добавление имеют haptic.
- Git/TEST разделены, готовность кнопок проверяется gateway и runner.
  TEST показывает настоящий результат JUnit/exit/длительность; техническая
  команда раскрывается отдельно. История открывает список заданий, журнал —
  отдельный экран с поиском, Share, меню copy/export и переходами начало/конец.
  Termux сгруппирован в компактные секции.
- Каталог HOME до 6 уровней, точный локальный путь, обычные репозитории и
  проверенные linked worktree. Лимиты/недоступные каталоги/ссылки обозначаются.
  Android/Python политики согласованы тестом. Нет исполнения произвольных команд.
- START требует зарегистрированный ID/путь; worktree и дополнительные проекты
  не могут запустить TEST/SYNC AnimaQuiz. Runner исполнения, protocol и SHA
  не менялись; сохранены старые releases, SQLite, Job ID, журналы и настройки.
- Установленный на телефоне helper 0.3.1 имеет верную SHA; новой release 0.4.0
  на момент проверки не было. Поэтому прежняя Beta требовала подключения.
  Теперь это «Обновить помощник», а не ложная ошибка. Исправлена подписка UI:
  изменение ready при создании gateway больше не теряется до регистрации listener.

## Ограничения

Только AnimaQuiz поддерживает исполняемые STATUS/CHECK/SYNC/TEST. Остальные
проекты и worktree — read-only метаданные. Содержимое diff, BUILD, Release/AAB,
отмена процессов, пакеты/обновления/Wake Lock, OAuth не реализованы.
Поиск не заходит внутрь уже найденного Git-дерева; вложенный там репозиторий
можно проверить по точному пути. Максимальная глубина 6 также относится к PATH.
Скрытый/внешний common gitdir, bare и submodule .git-файлы не подключаются.
Сканирование ограничено 1000 каталогами, 2000 записями на каталог, 40 проектами
и временем. Эти границы не выдаются за полный обход всей файловой системы.

Настоящая установка/обновление helper через Android callback и запуск новых
396 тестов остаются приёмкой владельца. Успешный старый результат не означает
готовность нового запуска. При активном/UNKNOWN задании helper не обновляется;
нужен QUERY прежнего Job ID. Во время разработки QuizApp не тестировался и его
исходники не изменялись. Автоматический повтор START отсутствует.

## Приёмка на Android без консоли

1. Обновить приложение APK поверх beta.1, не удалять старую версию и данные.
   Проверить старую историю, результат 396/396 и настройки ожидания.
2. Проекты: компактный список, «Добавить проект», контекстное меню удаления.
   Добавить один доступный проект и снова проверить список: дубликата нет.
   Удалить только его запись и найти повторно — файлы остаются.
3. Проверить поиск вложенных репозиториев. Для пропущенного использовать
   «По точному пути» → «Проверить путь». Ошибка/ограничение должны иметь причину.
   Worktree отображается для чтения. У другого проекта TEST/SYNC не запускаются.
4. AnimaQuiz: панель с состоянием и строками инструментов. Сборка недоступна.
   Git/Тесты/История открываются без нижней навигации, со стандартной стрелкой.
   Системный Back возвращает журнал → история → проект → список.
5. Из списка перейти Termux, затем системный Back: должен открыться список
   проектов. Не должно возникать перехода в чужой инструмент. Повернуть телефон
   на экране проекта/журнала; проект и Job ID должны сохраниться.
6. Меню → Настройки: темы system/light/dark и динамические цвета. Проверить
   обычный и крупный шрифт, узкий экран и landscape. Кнопки/текст доступны,
   нет перекрытия системными панелями или прыгающей прокрутки.
7. Git: при предложении нажать «Обновить помощник», дождаться подтверждения.
   Затем «Обновить локальное состояние» и «Проверить GitHub». Проверить branch,
   origin, SHA. SYNC только при безопасном fast-forward и отдельном подтверждении.
   При отсутствии обновлений не создавать их специально ради проверки.
8. Тесты → «Запустить тесты». Проверить текущий Job ID, монитор, блокировку Git,
   JUnit/exit/длительность. Во время TEST закрыть Activity и открыть вновь;
   отдельно force-stop именно AnimaDev через настройки Android и открыть вновь.
   Тот же Job ID, без второго START; Termux и данные не останавливать/не очищать.
9. История: выбрать старое и новое задание, убедиться в правильном результате.
   Журнал: Важное/Всё, поиск, конец/начало, выделение, copy, export, Sharesheet.
   Экспорт/Share относится к выбранному Job ID и содержит очищенный доступный лог.
10. Termux: «Проверить окружение», разрешения и версии. Выдать/отозвать разрешение
    уведомлений в системных настройках, вернуться: состояние актуально. Отказ
    уведомлений не блокирует TEST. Проверить root-выход и отмену выхода.

После готовности APK остановиться до оценки владельца. Внешние агенты/Bridge
не нужны установленному приложению. Push/Actions/операции с main отсутствуют.
