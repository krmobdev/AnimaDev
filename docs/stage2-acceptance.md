## Что реализовано

Светлый экран «Репозитории», профиль AnimaQuiz, ветка/SHA/origin/состояние,
отдельные кнопки STATUS, CHECK и подтверждаемый SYNC, журнал и раскрываемые
технические подробности. Реальный RUN_COMMAND с уникальным транспортным ID
и non-exported callback receiver. UI не ждёт Git синхронно.

Встроенный runner устанавливается отдельной кнопкой за пределами Git-дерева.
SHA-256 проверяется перед исполнением точных прочитанных байтов.
SQLite хранит задания, результаты и ограниченные логи. Неизвестный результат
не считается успехом. Возобновление — QUERY того же ID; автоповтора START нет.
Дочерний Git не получает разрешение начать до сохранения его идентичности.
Перед ff-only проверяются branch, origin, HEAD и чистота повторно.
Новых токенов в Android нет; используются существующие SSH и known_hosts Termux.

## Непроверенное и ограничения

- Новый APK ещё не проверен через Android UI: установка runner, реальный Git
  callback, разрешения, поворот, закрытие/возврат, поздние ответы и визуальная
  компоновка на телефоне требуют приёмки владельцем.
- GitHub SSH/fetch и SYNC производственного QuizApp не запускались.
- Фактическое убийство Android/Termux системой, перезагрузка устройства,
  повреждение SQLite/нехватка места и память устройства не проверены end-to-end.
- Маскирование распознаваемых форм секретов реализовано в runner и receiver;
  синтетические credential-тесты не включены в телефонный набор. Полный
  Android-путь маскирования остаётся непроверенным. Сырые трассировки не выводятся.
- Блокировка действует между AnimaDev-операциями, не между всеми внешними Git
  клиентами. Не выполнять внешний Git одновременно с операцией AnimaDev.
- Журнал ограничен 100 заданиями; при лимите запуск блокируется, история сама
  не удаляется. Это ограничение минимального этапа, не полноценный архив.
- Fetch ограничен 180 с, ff-only 60 с; UNKNOWN короткого callback через 15 с
  не останавливает Git и не разрешает повтор. QUERY продолжает уточнение.
- Произвольные команды, проекты, пути и Git-конфигурации из UI не принимаются.
  Тесты/сборки QuizApp в приложении отсутствуют.

## Ручная приёмка — только кнопки

1. Через «Загрузки» установить `AnimaDev_0.2.0_git_debug.apk` обновлением.
2. Открыть «Репозитории». При запросе дать системное разрешение Termux.
3. «Настроить локальный помощник» → «Настроить». Дождаться сообщения готовности.
4. «Обновить состояние». Ожидаются AnimaQuiz, test/decomposition-v1,
   корректный короткий SHA, origin совпадает и реальное состояние дерева.
5. «Проверить обновления». Дождаться результата; открыть технические подробности:
   реальный Job ID, terminal state, код Git-операции, длительность,
   stdout/stderr короткого Termux-ответа, exit 0 и err -1 при успешном транспорте.
6. Повторить CHECK и во время работы повернуть экран, затем закрыть и открыть
   приложение. Сохраняется один Job ID; второй запуск заблокирован.
   При UNKNOWN нажать «Уточнить состояние»: новый SYNC сам не запускается.
7. Если новых коммитов нет, SYNC должен быть недоступен. При наличии обновлений
   и чистой разрешённой ветке нажать «Синхронизировать» и отдельно подтвердить.
   После успеха SHA обновляется, behind 0; при ошибке показана причина.
8. Если фактическая ветка/remote не соответствуют профилю или дерево грязное,
   SYNC недоступен; приложение ничего автоматически не исправляет.

Для dirty/diverged/error сценариев не требуется создавать изменения в QuizApp:
они проверены fixtures; воспроизведение на телефоне пока не заявлено.
Команды в консоли для приёмки не нужны. После этой контрольной точки работа
останавливается до разрешения владельца.
