## Готово

- Material 3, динамические цвета Android, системная/светлая/тёмная тема.
  Оформление сохраняется. Системные отступы, edge-to-edge, стандартный масштаб
  текста; компактные плитки в две колонки, в четыре на широком экране.
- Верхняя навигация «Проекты» / «Termux». Рабочее пространство проекта:
  Git, Тесты, Сборка, История. Действия не теряют выбранный контекст.
- Локальный реестр проектов, безопасный поиск существующих Git-репозиториев,
  исключение уже добавленных, добавление, сохранение выбора, удаление только
  записи приложения. Файлы, журналы и задания при удалении записи не удаляются.
- AnimaQuiz использует существующие STATUS, CHECK, SYNC и TEST. START требует
  явные ID/путь проекта, без значений по умолчанию. Другие проекты не могут
  запускать операции AnimaQuiz. Runner повторно проверяет ветку/origin и политику.
- Сохранены RUN_COMMAND, callback/nonce/Job ID, QUERY без повторного START,
  блокировки конфликтующих операций, UNKNOWN, восстановление прежних заданий.
- TEST вынесен на свой экран, отдельно от Git. Результаты JUnit, длительность,
  монитор и журнал сохранены. Пороги предупреждений 5/10/15/20/30 минут и
  защитный предел TEST 90 минут не изменены.
- Терминальный результат не показывает прежние «Процесс жив» и текущий этап.
  Статус разрешения уведомлений перечитывается при возвращении на экран и
  после ответа системы. Устранены горизонтальные ряды длинных обрезаемых вкладок.
- Журнал: выбор задания в прокручиваемом списке, «Важное» / «Всё», поиск,
  выделение, копирование, экспорт, переход к началу/концу, перенос длинных строк,
  видимый индикатор прокрутки. Порционное чтение, лимиты и уведомление об усечении
  сохраняются; доступный журнал не ограничивается прежними 4096 символами.
- «Поделиться»: Android Sharesheet и очищенный текстовый файл, FileProvider
  открывает только cache/shared_reports, URI выдаётся с временным доступом.
  Получателя выбирает пользователь. Нет прямой интеграции с AI или отправки
  без выбора пользователя. Отчёт включает данные выбранного задания и snapshot
  его ветки/коммита, а не другого открытого проекта.
- Обзор Termux читает реальные Python/Git/Java, SDK, сохранённые Gradle,
  платформу и архитектуру. Нет установки пакетов или изменения окружения.
- Добавлена модель будущих сборок и отдельная архитектурная документация.

## Частично готово и отложено

- Дополнительные проекты: реестр и read-only метаданные готовы; выполнение
  STATUS/CHECK/SYNC/TEST поддержано только согласованным профилем AnimaQuiz.
  Остальные инструменты явно заблокированы с объяснением, без подмены пути.
- Каталог ограничен непосредственными публичными каталогами HOME и дочерними
  проектами HOME/anima-workspace. Символьные ссылки, скрытые/защищённые каталоги
  и .git-файлы worktree не подключаются. До 40 репозиториев, 120 кандидатов;
  ограниченность поиска обозначается. Другие корни требуют отдельной политики.
- Просмотр изменений показывает настоящие имена изменённых файлов; содержимое
  diff в этой Beta недоступно и явно обозначено как будущая функция.
- Сборка APK/AAB не подключена. Нет действующих кнопок BUILD. Будущие профили,
  worktree для иных веток, кеш и защищённые release secrets описаны, но не исполняются.
- Менеджер пакетов, обновления Termux, Wake Lock, отмена процессов, OAuth,
  Release/AAB не реализованы. Установленное приложение автономно, без Bridge/VPS.
- Исторический отчёт может не иметь ранее не сохранённых ветки/SHA: такие поля
  явно отмечаются. Новые страницы runner содержат snapshot. Старые данные сохранены.
- Уведомления используют прежнюю архитектуру без нового foreground service.
  Они не гарантируют выживание Termux и не обещают непрерывного обновления при
  выгруженном UI. Действительное состояние восстанавливается по Job ID.

## Android-приёмка без консоли

1. После разрешения блокировки передачи APK открыть AnimaDev_0.4.0_beta1_debug.apk и обновить установленное
   приложение. Не удалять прежнюю версию и не очищать данные. Проверить старые
   результаты, историю, журналы и порог предупреждения.
2. Открыть «Проекты» → AnimaQuiz. Проверить четыре инструмента. В «Вид» выбрать
   светлую/тёмную/системную тему и динамические цвета; проверить узкий экран,
   увеличенный системный шрифт и поворот. Текст и кнопки должны оставаться доступны.
3. Открыть Git. При необходимости нажать «Подключить помощник»: установка
   выполняется автоматически, без терминала и без удаления истории. Сначала
   «Обновить состояние», затем «Проверить GitHub». Проверить ветку/origin/SHA.
   «Получить изменения» доступно только при безопасном fast-forward и отдельном
   подтверждении. Если обновлений нет, не пытаться специально создавать их.
4. Открыть Тесты → «Запустить тесты». Проверить монитор, настоящую длительность,
   прогресс, блокировку Git во время TEST, затем JUnit и exit code. После окончания
   не должно быть старого «Процесс жив» или промежуточного этапа Git.
5. Во время TEST закрыть Activity через «Назад»/«Выйти», открыть снова: тот же
   Job ID, без повторного START. Отдельно принудительно остановить именно
   AnimaDev через системные настройки Android и открыть снова. Не останавливать
   Termux и не очищать данные. Должны восстановиться состояние и доступный журнал.
6. В «История» выбрать старое и новое задание. Проверить режимы, поиск,
   длинные строки, прокрутку, начало/конец, выделение, копирование и экспорт.
   Нажать «Поделиться», выбрать приложение, поддерживающее текстовые файлы;
   убедиться, что отчёт относится к выбранному Job ID и не содержит секретов.
7. В «Termux» обновить обзор. Выдать уведомления; вернуться и проверить
   актуальное состояние кнопки. Отозвать разрешение в системных настройках,
   вернуться: состояние должно обновиться, TEST не блокируется из-за уведомлений.
8. В «Проекты» → «+ Добавить проект» обновить список. AnimaQuiz не должен
   предлагаться второй раз. При желании добавить существующий иной проект:
   его TEST/SYNC должны быть недоступны, а QuizApp не должен запускаться за него.
   Удалить только запись этого проекта и снова найти его: файлы остаются.
9. Открыть «Сборка»: функция явно недоступна. Вернуться и проверить сохранение
   проекта, системную кнопку «Назад», отмену выхода и повторное открытие приложения.

Реальная Android-приёмка Beta, установка поверх 0.3.1, force-stop, темы/шрифты/
поворот, разрешения, экспорт и получение файла выбранным приложением пока не
подтверждены. Успешная компиляция не считается доказательством этих сценариев.
Безопасный аудит перечислил только семь ожидаемых assets (catalog и runner);
в APK нет тестовых файлов/fixture или файла настроек владельца. Изменение текста
редактором секретов найдено в Python-исходнике и при декодировании бинарных DEX.
Отдельный аудит DEX string table не нашёл строк, изменяемых тем же редактором.
Это не подтверждает наличие настоящих секретов и не раскрывает точный триггер
AnimaBridge; причину SECRET_CONTENT без данных его классификатора определить
надёжно нельзя. Значения потенциальных секретов не выводились.
Передача APK остаётся незавершённой до устранения блокировки AnimaBridge.
Следующие этапы не начинаются; реальная Android-приёмка ожидается после передачи.
