# Termux — подготовка локальной Android-сборки

## Управление AnimaBridge без открытия Termux (dev.50)
После первоначальной настройки Termux и RUN_COMMAND в AnimaDev достаточно кнопки «Запустить». Если диспетчер runit ещё не работает, приложение запускает его через фоновый RUN_COMMAND от пользователя Termux и затем включает зарегистрированную службу. Вручную открывать окно терминала не требуется. «Проверить» не запускает диспетчер и не меняет службы. Штатный Shizuku (UID shell) не может непосредственно исполнять Python в закрытом Termux HOME. Состояния «Диспетчер не запущен», «Агент запускается», «Конфликт с ручным агентом» не означают успешную работу Python; после запуска состояние проверяется отдельно. Android может ограничивать фоновый запуск после принудительной остановки Termux.


## Полный список веток GitHub в dev.47 (кандидат)
Кнопка «Обновить origin с GitHub» выполняет обычный Git fetch **со всеми `refs/heads/*`**, независимо от `remote.origin.fetch`. Это не `git reset` и не `git clean`; локальные изменения и рабочие каталоги не перезаписываются. Удалённые ссылки не очищаются автоматически. Для безопасного переключения приложение ещё раз сверит SHA напрямую с GitHub.

## Shizuku (необязательно)
AnimaDev dev.43 подключается к работающей службе Shizuku через официальный Android API. Вкладка **Termux → Shizuku** показывает состояние и предлагает разрешение, которое пользователь подтверждает в Shizuku. Для такого подключения не нужны скрипты `rish`, Root или постоянный ADB. Сама служба Shizuku должна быть запущена владельцем; после перезагрузки без root её часто нужно снова запускать через беспроводную отладку. Инструменты Termux работают независимо от Shizuku.


## Фоновая Release AAB в AnimaDev dev.41
Фоновый обработчик использует установленный SDK в `~/android-sdk`, когда RUN_COMMAND не передал ANDROID_HOME. Репозиторий остаётся неизменным.
Журнал содержит только названия задач Gradle и заранее разрешённые сообщения об ошибках. Секреты подписи не сохраняются. При подготовке к офлайн-сборке один раз выполните онлайн-сборку неподписанного AAB, чтобы зависимости попали в кэш.


Инструкция для существующего Termux. Команды запускайте **внутри Termux вручную**, только после проверки вывода. AnimaDev не устанавливает пакеты молча.

## 1. Базовые компоненты
```sh
pkg update
pkg install git python openjdk-21 curl unzip
termux-setup-storage
```
Проверьте: `java -version`, `python --version`, `git --version`. Откройте разрешение памяти, если Android его запросит.

## 2. Android SDK
Понадобятся Android SDK command-line tools, platform-tools, соответствующая версия Android Platform и build-tools. Храните SDK в известном каталоге, задайте `ANDROID_HOME` / `ANDROID_SDK_ROOT` согласно конфигурации вашего проекта. Для установки компонентов служит `sdkmanager` из уже установленного Android SDK; команды вроде `sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"` — только пример: **берите версии из** `build.gradle.kts` и вашего `gradle.properties`. На Termux стандартный desktop `aapt2` может быть несовместим с архитектурой Android: нужен рабочий Termux AAPT2 и соответствующий override, если он требуется вашему проекту.

## 3. Gradle
Используйте только проектный `./gradlew`. После загрузки необходимых зависимостей проверьте:
```sh
./gradlew --version
./gradlew :app:assembleDebug --offline --no-daemon --rerun-tasks --console=plain
```
При первой сборке `--offline` может не сработать — сначала легально скачайте необходимые зависимости. Не удаляйте `~/.gradle` и Android SDK: это приведёт к длительным повторным загрузкам.

## 4. Связь с AnimaDev
- Разрешите `RUN_COMMAND` в Termux и доступ AnimaDev в Android.
- В приложении нажмите «Проверить окружение», убедитесь в подходящих версиях JDK, SDK и инструментов.
- Проверьте SSH/GitHub, ветку и SHA, прежде чем запускать тесты или сборки.
- Для тестов на устройстве отдельно настройте ADB и авторизованное устройство.

## 5. Безопасность
Не копируйте закрытые JKS, пароли или SSH-ключи в общий Download. Не запускайте незнакомые скрипты из проектов. Инструкция ничего не устанавливает автоматически и не изменяет ваши Git-репозитории.

### Управление AnimaBridge через AnimaDev (dev.49)
Служба animabridge регистрируется через проверенный scripts/install_animabridge_service.sh; установка оставляет её остановленной. Не запускайте второй экземпляр агента при работающем ручном агенте. Карточка AnimaDev использует Termux RUN_COMMAND для sv status/up/down/restart и не читает секреты агента.
Подписанная Release APK использует локально установленные zipalign, apksigner, aapt, JDK и Android SDK. JKS передаётся только по защищённому локальному каналу.
