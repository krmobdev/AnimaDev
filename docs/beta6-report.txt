Ограничения
Ветки показывают локальные refs последнего fetch, не актуальный GitHub.
Расхождение обозначается по SHA; анализ ahead/behind для всех веток не добавлен.
Поиск относится к загруженным страницам; для остальных есть «Загрузить следующие».
При изменении refs во время чтения нужно обновить снимок.
SAF/SharedPreferences после установки проверяются владельцем; сохранение схемы
и ключей в коде не является доказательством фактического сохранения на устройстве.
B/C, переключение веток, сборки других проектов, Release/AAB, Actions, OAuth
и отмена процессов не реализованы. После передачи — остановка до приёмки.

Последующий коммит этого отчёта меняет только документацию. После него Termux
снова синхронизируется с точным GitHub SHA и выполняется offline Gradle-проверка;
финальный SHA синхронизации будет указан в сообщении владельцу.
