## Изменения

- Android Back на главном уровне: «Закрыть AnimaDev?» → «Отмена» / «Выйти».
  Выход использует finishAndRemoveTask(), не killProcess/System.exit и не
  останавливает Termux. При потенциально активном Git-задании есть предупреждение
  о продолжении работы и сохранении результата. Диалог и выбранный экран
  сохраняются при повороте, prefs/SQLite не очищаются.
- Ошибки fetch: DNS, сеть/соединение, SSH-авторизация, ключ сервера,
  недоступный репозиторий/ветка и неизвестная ошибка. Код Git сохраняется.
  Пользователь видит фиксированное объяснение, без сырых Git-диагностик/трассировок.
  После terminal FAILED безопасный CHECK можно повторить отдельным нажатием;
  автоматический SYNC отсутствует. Классификация диагностик эвристическая,
  LC_ALL=C стабилизирует сообщения Git, неизвестные ошибки дают общий fallback.
- При обновлении APK незавершённое задание опрашивается через прежний runner SHA.
  Старые releases и журнал не удаляются. После завершения старого задания
  обновление локального помощника выполняется кнопкой из нового APK.
- AGENTS.md и docs/architecture.md содержат требования одного аккаунта,
  будущего выбора локальных репозиториев без уже открытых, вкладок и независимых
  состояний/настроек/журналов, безопасного закрытия вкладки, поиска, clone и fork.
  Эти функции сейчас не реализованы. Новых токенов/паролей в APK нет.

## Android-приёмка через кнопки

1. Установить 0.2.1 поверх 0.2.0 из «Загрузок», без удаления приложения.
2. Открыть «Репозитории»: предыдущие состояние, Job ID и журнал должны сохраниться.
   Если старое задание ещё активно, дождаться его или нажать «Уточнить состояние».
3. При предложении обновить помощник нажать «Настроить локальный помощник» →
   «Настроить», затем «Обновить состояние» и «Проверить обновления».
4. Нажать системный «Назад»; проверить «Отмена». Открыть диалог снова,
   повернуть экран: диалог остаётся. «Выйти» закрывает task и убирает его из недавних.
5. Во время CHECK повторить выход: должно быть предупреждение. Открыть AnimaDev
   вновь: тот же ID и сохранённый/уточняемый результат, без повторного запуска CHECK/SYNC.
6. Если возникает DNS/сетевая ошибка, видно понятное сообщение и реальный код.
   Восстановить связь обычными настройками Android и нажать CHECK отдельно.
   При доступной сети результат успешен; SYNC автоматически не запускается.

Новая установка/обновление, Back-жест, поворот и выход во время Git ещё требуют
реального Android-теста. Наличие fast-forward в fixtures не является приёмкой
SYNC на телефоне. Этап 3 не начинался. Push/Actions/изменения QuizApp отсутствуют.
