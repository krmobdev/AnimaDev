# AnimaDev — руководство пользователя

[English](USER_GUIDE_EN.md) · [Главная](../README.md) · [Сборка AnimaDev](BUILD_FROM_SOURCE.md) · [История изменений](../CHANGELOG.md)

AnimaDev помогает работать с **существующими Git-проектами на Android через Termux**: проверять ветки, запускать Gradle-тесты, собирать APK/AAB и возвращаться к журналам заданий. **AnimaBridge Agent не обязателен** для Git и Gradle. Shizuku тоже необязателен.

## 1. Первое подключение

1. Установите **Termux** из доверенного источника и откройте его хотя бы один раз.
2. Разрешите в Termux `RUN_COMMAND`: задайте `allow-external-apps=true` в `~/.termux/termux.properties` и предоставьте AnimaDev запрошенное Android-разрешение. Подробности — в [инструкции Termux](TERMUX_SETUP.md).
3. Откройте **AnimaDev → Termux → Проверить окружение**. Убедитесь, что доступ к Termux подтверждён.
4. Добавьте **существующий** локальный Git-репозиторий во вкладке **Проекты**. AnimaDev не клонирует проекты автоматически.
5. Откройте инструменты выбранного проекта. Перед действиями с ветками проверьте локальное состояние, `origin` и SHA удалённого коммита.

Для запуска Gradle-сборок в Termux отдельно понадобятся **JDK 21**, Android SDK и совместимый AAPT2. Для первого получения зависимостей нужен интернет; см. [подготовку Termux](TERMUX_SETUP.md).

## 2. Проекты, Git и рабочие каталоги

На экране проекта находятся инструменты **Git**, **Тесты**, **Сборка** и **История**. Раздел рабочих каталогов (*worktrees*) можно развернуть: для каждого показаны ветка, путь, локальный SHA и незакоммиченные изменения.

- **Обновить список каталогов** — прочитать локальный Termux; это **не** запрос к GitHub.
- **Обновить origin с GitHub** — отдельная сетевая операция, обновляющая доступные ссылки на удалённые ветки.
- **Проверить обновления / SHA** — сравнить локальное состояние и данные GitHub.
- **Переключить ветку** — разрешено лишь после проверки чистоты дерева, совпадения ожидаемых SHA и возможности безопасного перехода.
- Синхронизация не делает скрытых `git reset --hard`, `git clean` или `force push`; конфликт и незакоммиченные файлы не уничтожаются автоматически.

**Важно:** совпадающие SHA локального и удалённого коммитов **не означают**, что рабочее дерево чистое. Изменения файлов проверяйте отдельно. Открытые Git worktree тоже не переключаются и не удаляются без явного действия.

## 3. Тесты, сборки и журнал

**Тесты.** Для поддерживаемого проекта запускаются разрешённые Gradle unit-тесты. Инструментальные тесты на устройстве требуют отдельно настроенного и авторизованного ADB. Результат считается подтверждённым только по успешному завершению и актуальным отчётам.

**Debug APK.** Откройте **Сборка → Debug APK**. Перед сборкой проверьте ветку и исходники. Готовый APK проверяется по размеру и SHA-256 и открывается через системный установщик Android. Может потребоваться разрешение устанавливать APK из AnimaDev.

**Release APK / AAB.** Для подписи нужен **ваш собственный** JKS, alias и пароли. Подписанная APK устанавливается через Android, AAB предназначен для публикации, а не установки касанием. Не помещайте JKS и пароли в GitHub или общую папку загрузок.

**История и журнал.** У каждой операции есть ID. Если отображается `UNKNOWN`, это **не** доказательство ошибки и **не** повод начинать вторую сборку: откройте историю и запросите состояние **того же ID**. Закрытие интерфейса не означает остановку Gradle-процесса в Termux.

**Файлы.** Можно выбрать доступную папку в памяти устройства или стандартные «Загрузки». Очистка временного кэша AnimaDev не должна удалять пользовательские Git-репозитории, историю Termux, JKS или SDK.

В списке виджетов отдельно доступны **AnimaBridge Компактный (4×2)** и **AnimaBridge Панель (4×3)** с предпросмотром. Установленный ранее виджет после обновления становится компактным; расширенную панель можно добавить отдельно. Оба управляют одним агентом.

### Подписать готовый APK без Gradle

В проекте откройте **Сборка → Подпись APK**, выберите **неподписанный** .apk через системный проводник и **файл назначения** через «Выбрать куда сохранить». Исходный файл не изменяется. Выберите JKS из библиотеки или добавьте новый (с alias). Можно сохранить несколько ключей и назначить один **основным для проекта**. Release APK/AAB использует этот же основной ключ. Если пароль уже сохранён через Android Keystore, вводить его повторно необязательно; сохранение добровольное.

AnimaDev копирует APK во временный файл в «Загрузках», передаёт JKS и пароль в Termux **только внутри одноразового зашифрованного сообщения**, выполняет zipalign + apksigner, проверяет подпись, сертификат и SHA-256 и переносит результат в выбранный файл. Старый подписанный APK не переподписывается. При статусе UNKNOWN **не запускайте подпись повторно**, пока не проверили результат: копия может уже существовать. Сохранённый сертификат должен совпадать с установленным приложением для обычного обновления.

## 4. AnimaBridge — необязательное управление агентом

AnimaDev **не устанавливает и не содержит AnimaBridge Agent**. Если агент уже установлен отдельно, служба `animabridge` должна быть зарегистрирована в Termux через `termux-services` (см. [подготовку Termux](TERMUX_SETUP.md)).

В **Termux → AnimaBridge** доступны:

- **Проверить** — прочитать локальный статус runit/процесса, ничего не запускать.
- **Запустить** — разрешить запуск существующей службы. Когда запуск подтверждён, включается её постоянный автозапуск runit.
- **Остановить** — остановить службу и отключить её автозапуск; это осознанная остановка.
- **Перезапустить** — доступно только при подтверждённом запущенном процессе. Для остановленной службы используйте «Запустить».

Если служба ещё не зарегистрирована, сначала настройте её. **Не запускайте две копии агента:** ручную и под `runit` одновременно.

### Плитка в шторке и виджет рабочего стола

В карточке AnimaBridge нажмите **«Добавить в шторку»**. После системного подтверждения приложение покажет «Плитка добавлена»; удалить её можно через редактирование плиток Android.

Для рабочего стола используйте **«Добавить виджет»** или меню Android **Рабочий стол → Виджеты → AnimaDev**. Доступны отдельные варианты **4×2** (процесс, автозапуск, последняя проверка, связь с сервером не подтверждена, быстрые кнопки) и **4×3** (подробная панель с четырьмя кнопками). В списке виджетов показываются статические превью; они не являются живыми показаниями агента. Размер можно менять средствами лаунчера.

Нажатие на заголовок виджета открывает **существующую** задачу AnimaDev вместо создания дополнительного экрана. Одна плитка/виджет **не создаёт новый экземпляр агента**.

**Различайте:** `runit` запущен, Python-процесс запущен, автозапуск включён и **серверная связь подтверждена** — это разные состояния. Зелёный локальный статус Python сам по себе не доказывает подключение к серверу. На некоторых оболочках Android фоновые команды после принудительной остановки Termux могут быть ограничены.

## 5. Shizuku, интерфейс и язык

**Shizuku необязателен.** Он используется для подключения и диагностики системного Binder API; через него **не исполняются** команды в закрытом каталоге Termux. Запустить и разрешить Shizuku нужно отдельно.

В **Настройки → Внешний вид** можно сменить тему (Pulse / Emerald Glass) и язык (системный, русский, английский). Сырые журналы команд, SHA и пути намеренно не переводятся. Навигация и проекты сохраняются при смене оформления.

## 6. Что проверить при ошибках

| Симптом | Действие |
| --- | --- |
| AnimaDev не видит Termux | Проверьте установку Termux, `allow-external-apps`, разрешение RUN_COMMAND и вкладку «Termux → Проверить» |
| Ошибка JDK / Android SDK / Gradle | Проверьте JDK 21, реальный путь SDK и настройки [Termux](TERMUX_SETUP.md) |
| Сбой AAPT2 на телефоне | Используйте Android-совместимый AAPT2 и корректную настройку Gradle |
| `UNKNOWN` после сборки | Запросите статус **исходного ID**, не запускайте ещё одну задачу вслепую |
| SHA совпадает, но файлы изменены | Проверьте `git status`: коммит и рабочее дерево — не одно и то же |
| APK не устанавливается поверх прежней | Возможно, другая подпись APK; **не удаляйте установленное приложение без резервной копии** |
| Агент работает, но сервер недоступен | Проверьте отдельно сеть/агент; `sv status` подтверждает только локальную службу |
| Виджет не предлагает системное добавление | Откройте список виджетов лаунчера и добавьте AnimaBridge вручную |
