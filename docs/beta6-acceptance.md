# Приёмка AnimaDev 0.4.0-beta.6

Установить APK поверх beta.5 без удаления приложения. Команды в консоли не нужны.

1. Меню → Настройки. Проверить семь строк с иконками, светлую/тёмную/системную тему и динамические цвета. Выбор темы — диалог, динамические цвета — переключатель.
2. Поиск: «тёмная», «прогресс», «папка». Открыть результат, вернуться: запрос должен сохраниться. Повернуть экран при поиске и открытом диалоге. Проверить крупный системный шрифт и клавиатуру.
3. Убедиться, что прежние тема, интервал ожидания и SAF-папка Builds&Report сохранены. Экспортировать журнал дважды: два разных файла в выбранной папке. При утрате доступа повторно выбрать папку либо отказаться и использовать Downloads.
4. Уведомления: изменить разрешение в Android, вернуться — статус перечитывается. Отказ не блокирует операции.
5. AnimaQuiz → История → прежний TEST 396/396. «Важное»: понятная сводка, нет длинных command/step. «Всё»: раскрыть команду, найти текст, скопировать и экспортировать точный очищенный вывод. Проверить timestamp, зелёный успех и янтарное предупреждение.
6. Ветки: обновить локальный список. Одинаковые local/origin объединены; разные SHA показаны отдельно. origin/HEAD закреплён золотым только при подтверждении. Проверить дату коммита и отдельное время чтения, поиск и следующие страницы. Этот экран не выполняет fetch и не переключает ветки.
7. Добавление проектов: группировка worktree сохранена, путь не повторяет название без пользы. Проверить Back и отсутствие смены контекста проекта.
8. AnimaQuiz: STATUS/CHECK и TEST выполняются существующим runner; во время TEST Git заблокирован. Закрыть Activity/force-stop Android-приложение, открыть вновь: прежний Job ID, действительный результат и журнал, без повторного START.

SYNC с реальными новыми коммитами — отдельная осторожная приёмка владельца; агент не изменял QuizApp. Нет автоматической установки APK, проверки UI на устройстве или доказательства сохранности SAF средствами JVM. Этапы B/C не начаты.
