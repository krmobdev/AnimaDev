# Android-приёмка этапа A — beta.5

Установить APK поверх beta.4, не удаляя приложение. Code 10, min API33.

1. Проверить прежние проекты, журнал 396/396, историю и порог ожидания.
2. Открыть журнал из Тестов, затем из Истории. Back возвращает к источнику.
   Убедиться в жирных контрастных [HH:mm:ss], зелёном реальном SUCCEEDED /
   BUILD SUCCESSFUL, красных ошибках и янтарных предупреждениях. Длинная строка
   переносится; поиск, копирование, начало/конец, режимы и шаринг сохранены.
3. Меню → Настройки: шесть категорий. Зайти в каждую; стрелка и системный Back
   сначала возвращают к списку настроек. Повернуть экран, сменить тему,
   увеличить системный шрифт. Проверить чтение текста и отсутствие наложений.
4. Файлы и загрузки: исходное значение — Загрузки. Экспортировать журнал,
   проверить новый уникальный файл и временное сообщение с часами.
5. Выбрать существующую подпапку Download/Builds&Report через Android-проводник.
   Папка не создаётся автоматически. Экспорт проверить в выбранной папке.
   Повторный экспорт не должен перезаписывать первый файл. Перезапустить приложение.
6. Через системный проводник временно переименовать выбранную ТЕСТОВУЮ папку
   или отозвать URI-доступ. Вернуться в AnimaDev: один понятный диалог,
   повторный выбор восстанавливает сохранение. При отказе либо отмене выбора
   приложение возвращается к обычным Загрузкам без бесконечных предупреждений.
   Не удалять папку с пользовательскими файлами ради проверки.
7. Проекты → Добавить → поиск: обычные репозитории и worktree посчитаны отдельно.
   Worktree одного общего .git объединены в проект; копии и разные репозитории
   не объединены только из-за одинакового имени или URL.
8. Открыть проект: его worktree перечислены внутри рабочей панели. Просмотр
   не переключает текущую ветку и не запускает задания другого пути.
9. «Ветки · просмотр» → «Обновить список»: имя, SHA и дата коммита;
   активная локальная ветка выделена. Главная ветка закреплена золотым акцентом
   только при валидном origin/HEAD. Если его нет — честное «не определена»;
   network/fetch и угадывание main/master не выполняются. Снимок имеет время чтения.
10. Проверить STATUS/CHECK и реальный TEST AnimaQuiz обычными кнопками.
    Во время TEST закрыть/принудительно остановить только AnimaDev, затем открыть:
    восстанавливаются ID, действительный результат и доступный журнал без второго START.
    Эти реальные запуски — приёмка владельца, разработчик исходники QuizApp не меняет.

Не реализованы в A: checkout/clone, многопроектный runner, APK/AAB других проектов,
Actions/Releases-артефакты, отмена и возобновление скачивания. Тестировать их
в этой версии нельзя: соответствующего конвейера пока нет.

SAF и Android Sharesheet, аппаратные темы/размеры шрифта и force-stop должны
проверяться на телефоне. JVM-компиляция сама по себе их не подтверждает.
