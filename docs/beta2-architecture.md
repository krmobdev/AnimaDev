# Beta.2: иерархия и безопасное обнаружение

Корневые экраны: Проекты / Termux. Выбор корневого раздела сбрасывает внутренний
маршрут, сохраняя выбранный проект отдельно. Панель проекта и инструменты не
имеют нижней навигации. Back: журнал → история → панель → список; настройки
возвращают прежний экран. Возврат из Termux открывает список проектов.
NavigationState — чистая тестируемая модель; поля Activity сохраняются через
rememberSaveable, выбранный профиль дополнительно через projects_v1.

Панель проекта: компактный блок branch/SHA/dirty и четыре строки инструментов.
Сборка недоступна непосредственно в панели, без отдельного пустого экрана.
История показывает задания, журнал открывается отдельно. Управление текстом:
поиск/обновление/Share в панели, copy/export в меню; переходы начало/конец снизу.
Все иконки — официальные Material Symbols Outlined 24px, Google Apache 2.0.
Источник: https://github.com/google/material-design-icons/tree/master/symbols/android
Лицензия: material-symbols-LICENSE.txt. Новых Maven-зависимостей не добавлено.

Каталог HOME: max depth 6, max 1000 обходов каталогов, max 2000 элементов в
одном каталоге, max 40 репозиториев, ~20 с обхода + ~20 с чтения метаданных
(каждое отдельное Git-чтение ограничено 2 с). Временные границы допускают
завершение уже начатого ограниченного чтения. Callback каталога истекает за 75 с.
Вложения доступны и вне anima-workspace; защищённые компоненты запрещены на
любой глубине. Python/JVM политика проверяется на согласованность тестом.
Скрытые, storage, SDK, Gradle, build/dist/target, кеши, node_modules, venv/env,
secrets/credentials/keystores не обходятся. Произвольные symlink исключены.
После найденного Git-репозитория сканирование его рабочей копии не продолжается;
для вложенного репозитория используется точный путь. PATH — фиксированное
чтение метаданных, а не команда пользователя. Путь проверяют Android и Python.

Linked worktree допускается только при обычном .git-файле <=4096 bytes,
каноническом target под разрешённым базовым repository/.git/worktrees/name,
валидном commondir и обратном gitdir на исходный marker. Symlink не допускаются.
Проверяются обычная и worktree-конфигурация, опасные include/filter/url/helper
настройки блокируют чтение Git-статуса. Worktree получают read-only профиль.
Внешний/скрытый common gitdir, submodule .git-файл и bare repository не подключаются.
Отказы/ограничения записываются в issues; секретные скрытые имена не перечисляются.

В Beta.2 runner исполнения не переписан и его SHA сохранён. На устройстве на
момент разработки установлен runner 0.3.1; это объясняет необходимость обновления
помощника в первой Beta. Кнопка теперь различает подключение и обновление.
Готовность означает подтверждённый INSTALL callback/контрольную сумму, а не старые
396 результатов. Старые активные ID используют прежний runner для QUERY, пока
новый START заблокирован. Обновление не заменяет старые releases/SQLite/журналы.
Сам настоящий installer из APK выполняется в отдельных fixture, в том числе
повторно, при неверной SHA и symlink. Уже установленный runner телефона не
обновляется через Bridge вместо UI: эту часть проверяет владелец кнопкой.
